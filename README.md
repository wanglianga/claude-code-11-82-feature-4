# 区域影像中心受控分析平台

基于 **Vue 3 + Spring Boot 3 + PostgreSQL** 的受控影像分析沙箱。平台只处理**结构化影像特征与随访**，
不存储、不输出任何原始影像或患者级身份记录；通过批准编译、联合推断审查、累计披露预算与交付冻结/复现，
防止由多次合法聚合反推出小群体。

## 一、核心能力与对应实现

| 题目要求 | 实现位置 |
| --- | --- |
| 批准编译器生成可复现队列与字段投影 | `ApprovalService`、`CohortService`（确定性 JSON + specHash/cohortHash） |
| 查询解析器规范化筛选/分组/时间窗/输出，并与批准范围相交 | `QueryParser`（注释等展示文本不入哈希） |
| 结果关系账（队列/维度/过滤/抑制/舍入/水位） | `QueryAttempt`、`Deliverable.manifestJson` |
| 推断审查器：以所有已披露输出 + 公开总数为约束计算受抑制单元可行整数区间 | `InferenceEngine`（界传播 + DFS 可行性枚举）、`DisclosureReviewService` |
| 披露预算按研究空间 + 有效期累计窄化程度，不随查询文本/版本号重置 | `BudgetService`、`BudgetLedger`（空间×季度账本） |
| 交付器冻结结果/算法/审批/审查证明；复现器按当时审批与水线重建 | `DeliverableService`（sha256 清单 + 逐单元复现比对） |
| 最小发布单元 5；每空间每季度 10 风险点；唯一计数硬阻断；耗尽后仅零窄化结果 | `ResearchSpace`、`DisclosureReviewService` 裁决链 |
| 固定表组整组联合核验 / 交互会话实时扣共同预算（同一规则两条路线） | `reviewTableSet` / `review` + `InteractiveSession` |
| 撤回/到期拒新读，旧结果仅审计留存；算法升级只新增版本不改写旧结论 | `ApprovalService.requireReadable`、`AnalysisVersionService`、`DataSeeder`(feat-v1/v2) |
| 链接版本封存包：保留提供方输入批次/令牌化规则版本/候选阻断规则/用途授权快照/受控匹配权限/成员摘要 | `LinkSealService`、`LinkVersion`、`sealPackageJson` |
| 密钥轮换后按旧规则+旧授权快照恢复原成员；两条路线（托管封条重放 / 提供方重建） | `LinkRebuildService`、`LinkMatchingEngine`、`LinkMatchSeal`、`ProviderRebuildAuthorization` |
| 成员一致性验证器：逐项摘要核对，`REPRODUCED/DIVERGED/EVIDENCE_INCOMPLETE` 三态；不一致阻止称为旧实验复现并输出差异调查 | `LinkRebuildService.verify`、`LinkRebuildRun` |
| 用途授权/输入批次缺失进入“证据不完整”而非成员漂移 | `LinkRebuildService.recordEvidenceIncomplete` |
| 到期证明：删除逐例恢复能力，仅留不可逆统计审计摘要，明确不能再逐例复现 | `LinkExpiryService`、`LinkExpiryCertificate` |
| 令牌谱系账：封存/轮换/重建/核对/证据缺失/到期全程可追溯 | `TokenLineageEvent`、`LinkTokenService.lineage` |

### 风险点如何计算

- 候选约束分两层：**基线层** = 历史约束 + 本次抑制承诺（抑制是平台安全保证，不计点）；
  **增量层** = 精确披露等式、舍入区间、分区恒等。
- 对每个受保护单元（真实计数 < 5），比较加入增量约束前后的可行整数集合，
  **每少一个可能值计 1 点**；可行集被约束为唯一值时，无论预算余额一律硬阻断。
- 阻断不扣点、不留约束；同语义查询重复提交幂等零扣点；预算耗尽后只放行增量为 0 的结果。

## 七、链接版本封存与受控重建（院外令牌链接）

对应题目“院外令牌链接必须在研究批准的复现期限内，即使轮换密钥，也能恢复某次旧分析的原成员，
同时不让研究者长期持有可识别映射”。核心设计：

- **版本封存包**（`LinkVersion`）：每个已批准链接版本冻结一份复现闭包，包含当时的提供方输入批次、
  令牌化规则版本、候选阻断规则、用途授权快照、可调用的受控匹配权限与成员摘要（汇总 + 逐成员摘要 +
  摘要根）。封存包哈希、密钥代际与规则版本一并记账。
- **令牌谱系账**（`TokenLineageEvent`）：封存 / 密钥轮换 / 受控重建 / 一致性核对 / 证据缺失 / 到期
  全程只追加留痕，记录 kid、规则版本、成员摘要根与操作者。
- **两条留存路线**（封存时二选一，均须在复现期限内恢复原成员）：
  - `ESCROW_SEAL` **托管封条重放**：托管密钥加密的短期逐例匹配封条，重放快，但托管面较大；
  - `PROVIDER_REBUILD` **提供方重建**：只留旧输入 + 旧规则 + 期限内的提供方重建授权，每次重新匹配，
    留存映射最少，但要求提供方在期限内可用。
  选择依据（提供方可用性、托管风险、重放频率）记录在 `strategyRationaleJson`，界面可见。
- **受控重建**（`LinkRebuildService`）：密钥轮换后，只按封存包记录的**旧规则 + 旧密钥代际 + 旧用途
  授权快照**重新生成成员（而非当前默认规则/新密钥），再与封存摘要逐项核对。
- **成员一致性验证器**：三态结论 `REPRODUCED_OK` / `DIVERGED` / `EVIDENCE_INCOMPLETE`。
  `DIVERGED` 时系统禁止把结果称为该旧实验的复现，并输出差异调查（缺失/多出/摘要不一致令牌数与核查清单）；
  用途授权或输入批次在期限内缺失、或提供方不可用导致重建路线无法重新匹配时，进入“证据不完整”而非
  允许成员漂移。
- **到期证明**（`LinkExpiryService`）：复现期限届满后销毁逐例恢复能力（托管封条密文、提供方逐例输入
  批次、重建授权），只保留不可逆统计审计摘要（成员数、院别分布、摘要根），并明确记录“不能再逐例复现”。

演示数据预置两条路线（托管封条 / 提供方重建），均绑定 APV-S2 与 WL-2026Q4。登录后打开“链接版本封存与
重建”视图即可：轮换密钥 → 对旧版本执行受控重建 → 查看逐项摘要一致；也可切换“当前新密钥重建”观察必然漂移
与被阻断的复现声明；置提供方不可用观察证据不完整；签发到期证明后逐例重建返回 410。

### 2. 端到端场景验证（48 项断言）

后端启动后（建议先用全新数据库，脚本会撤回 APV-S2）：

```bash
python3 backend/e2e_verify.py
```

覆盖：

1. **14/1 联合阻断**：总数表放行后，医院表干跑即识别 `hospital=B` 可行集被唯一推为 `{1}`，
   正式提交 BLOCKED 且不扣预算；固定表组（总数+医院）整组阻断；改用舍入到 5 后 B 被抑制、可行集恢复多值并放行。
2. **8/7 保留可用结果**：两单元均 ≥5，医院表 A=8/B=7 放行；同语义查询重复提交零扣点；
   冻结交付物后按当时审批与水线逐单元复现成功（outputMatch / cohortHashMatch / sha256 均一致）。
3. **撤回与到期**：撤回 APV-S2 后新查询返回 403，旧交付物仍可审计读取与复现（标记 approvalReadableNow=false）；
   到期批准新建版本被 403 拒绝。
4. **算法升级**：feat-v2 生成独立新版本并重新参加预算审查，旧交付物载荷哈希不变、未被改写。
5. **预算耗尽规则**：管理员把季度上限压到已用量后，窄化查询（1 风险点）被预算阻断，
   零窄化查询仍 ALLOWED 且账本不增长。
6. **链接版本封存与受控重建**：现场封存两条留存路线；校验封存闭包六要素齐全；轮换密钥后两条路线仍
   逐项一致恢复原成员；用新密钥重建判定 `DIVERGED` 且禁止称为旧实验复现并输出差异调查；提供方不可用 /
   用途授权快照缺失均进入 `EVIDENCE_INCOMPLETE`（拒绝成员漂移）；强制到期后逐例重建返回 410，仅留
   不可逆统计审计摘要。

## 九、安全边界说明

- 对外输出单元对被抑制数据不携带真实计数（`displayCount=null`），真实值仅存于内部台账与审计。
- 变量按 `批准@水线` 作用域隔离，不同队列的同名维度不会跨队列错误串扰。
- 可行性枚举设解数/节点上限，触顶时 fail-closed 阻断，避免在超大解空间下给出不完整的安全结论。
- 链接版本：令牌只在相同用途作用域内可关联（作用域参与 HMAC 输入）；封存密钥代际材料仅存于托管面，
  API 只暴露指纹与托管引用；受控重建强制按封存旧规则/旧密钥/旧授权快照，且受匹配权限调用上限约束；
  `DIVERGED` 与 `EVIDENCE_INCOMPLETE` 均禁止声称复现；到期后销毁逐例能力、仅留不可逆统计摘要。
